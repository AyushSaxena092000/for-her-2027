# For Her — Birthday 2027

A responsive single-page birthday and fourth-anniversary site.

## Personalise before sharing

- In `index.html`, replace “Happy 26th, my love.” with her name.
- Replace the three memory cards with photos (or links/embedded reels) you both love.
- Update the timeline with your real memories.

## Preview locally

Open `index.html` directly in a browser, or deploy the whole folder to Netlify, Vercel, or GitHub Pages.
